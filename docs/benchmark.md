## 제품 판단

첫 버전의 우선순위는 **요청 작성 → 실제 전송 → 결과 확인 → 저장 → 파일로 이동 → 다시 복원**이다. 이 흐름을 자동 테스트할 수 있게 만든다. Postman의 전체 기능을 이번 버전에 포함한다는 의미는 아니다.

- 한국어 인터페이스, 단축키, 응답 상태·소요 시간·크기를 같은 화면에 제공한다.
- 브라우저의 CORS 제한과 무관하게 데스크톱 프로세스에서 HTTP(S)를 전송한다.
- 계정이나 별도 서비스 없이 SQLite에 기록한다. 가져오기는 검증 후 트랜잭션으로 반영한다.
- Postman 형식은 지원 가능한 필드를 명시하고 지원하지 않는 인증·본문은 가져오기를 중단한다. 스크립트 제외는 미리보기에 표시한다.

## 기술 선택

Electron은 Windows 설치 도구와 Node 네트워크 API를 함께 쓰기 편하고, React/TypeScript로 요청 편집기와 상태 흐름을 빠르게 검증할 수 있어 선택했다. Chromium 포함으로 설치 크기·메모리 부담이 있으므로 실제 측정 후 개선한다. 현재 Tauri나 경쟁 제품보다 가볍다고 주장하지 않는다.

화면에는 Node 권한을 주지 않고 제한된 preload API를 제공한다. 인증서 검증을 유지하고, 응답 HTML은 실행하지 않는다. [Electron 보안 지침](https://www.electronjs.org/docs/latest/tutorial/security)

NSIS의 `oneClick: false`로 설치 경로를 선택하는 마법사를 구성한다. 이는 요청한 InstallShield 형태의 설치 경험을 위한 선택이다. [electron-builder NSIS 문서](https://www.electron.build/docs/nsis/)

## 이후 성능 비교 방법

Windows x64의 동일 PC, 동일 로컬 서버, 동일 응답으로 비교한다. 도구 버전, CPU·메모리, 요청 수, 표본 수를 기록하고 처음 실행과 반복 실행을 분리한다.

| 지표          | 시나리오                             | 초기 목표                |
| ------------- | ------------------------------------ | ------------------------ |
| 시작 시간     | 프로세스 시작부터 URL 입력 가능까지  | p95 3초 이하             |
| 히스토리 반응 | 10,000건에서 첫 100건 표시           | p95 200ms 이하           |
| 요청 오버헤드 | 로컬 1KB 응답, 직접 HTTP 호출과 비교 | 추가 지연 p95 30ms 이하  |
| 응답 표시     | 1MB JSON 응답                        | 입력 UI가 멈추지 않을 것 |
| 백업 무결성   | 한글·중복 키·바이너리 포함 왕복      | 지원 필드 손실 0건       |

목표 수치는 측정 결과가 아니다. 실제 Windows 결과를 확보하면 별도 버전 기록에 추가한다.
