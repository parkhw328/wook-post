## 재현

Node.js 24 이상, npm, 로컬 Docker를 사용한다. 이번 번들은 호스트 Node.js 26.8.1에서 생성했다. Electron 44.7.0, electron-builder 26.15.3, NSIS 3.0.4.1과 기존에 고정한 builder 이미지를 사용했다.

```bash
npm ci
npm run check
xvfb-run -a -s '-screen 0 1600x1000x24' npm run test:e2e
docker run --rm --platform linux/amd64 \
  --mount "type=bind,src=${PWD},dst=/project,readonly" \
  --mount "type=bind,src=${PWD}/release,dst=/project/release" \
  --workdir /project --entrypoint /bin/bash \
  electronuserland/builder@sha256:41ae540902461b6cbc988987db79547fcc10cda04d2a6c6367504f59d4b37c64 \
  -lc 'node node_modules/electron-builder/out/cli/cli.js --win nsis --x64 --publish never'
cd release/1.1.0
sha256sum wPost-1.1.0-x64-Setup.exe > wPost-1.1.0-x64-Setup.exe.sha256
sha256sum -c wPost-1.1.0-x64-Setup.exe.sha256
```

Windows x64에서는 `npm ci` 후 `npm run dist:win`으로 같은 버전의 설치 파일과 체크섬을 생성한다. 빌드 타임스탬프 등에 따라 새 설치 파일의 체크섬은 달라질 수 있다.

`main`과 `v1.1.0`을 원격에 푸시한 후 저장소의 `npm run release:publish` 절차로 초안 업로드·재다운로드 해시 비교·Latest 공개를 수행한다. 최신 릴리스 정책과 Windows 확인 항목은 [배포 절차](../releasing.md)를 따른다.
