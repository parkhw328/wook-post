## 이번 빌드

ALPHA 표시를 제거하고 영문 JetBrains Mono·한글 Noto Sans KR를 포함했다. UI 16px, URL·본문·응답 17px, 보조 정보 최소 14px를 적용한다. 응답 복사, JSON 값 보존, 히스토리 중복 표시 수정 내용을 포함한다. [점검 기록](../reviews/v0.1.0.md)과 [변경 이력](../../CHANGELOG.md)을 참고한다.

설치 `appId: com.parkhw328.wookpost`, 사용자 데이터 위치 `%APPDATA%/Wook Post/wook-post.sqlite`, 백업 스키마 v1은 유지한다. 이전 버전 설치 파일과 태그는 보존한다.

## 환경과 검증

Rocky Linux 로컬 환경에서 번들을 생성하고, 고정 Docker 이미지의 Node.js 24.15.0 / Wine 11.0으로 Windows x64 NSIS 패키지를 만들었다. Electron 44.7.0, electron-builder 26.15.3, NSIS 3.0.4.1을 사용했다.

- `npm run check`: TypeScript·Prettier·단위/통합 테스트 **28개 통과**.
- `xvfb-run -a npm run test:e2e`: 실제 Electron 시나리오 **5개 통과**.
- 기본 1440×940 및 최소 1000×700 창의 요청·응답·환경 설정·앱 정보 확인. Chromium에서 실제 영문·한글 번들 글꼴을 사용함을 확인.
- 7-Zip NSIS 무결성 검사: `Everything is Ok`.
- `wPost.exe`는 x86-64 PE. 설치 부트스트랩 자체는 PE32이다.
- 앱과 설치기의 제품명 `wPost`, 파일 버전 `0.1.0`, 제작자 `Hyunwook Park` 확인. 앱의 숫자형 제품 버전은 `0.1.0.0`, ASAR 앱 버전은 `0.1.0`이다.
- ASAR에 JetBrains Mono Regular/Bold와 Noto Sans KR 원본 TTF 3개가 포함됐으며 소스와 SHA-256이 일치한다. 디자인 자산 라이선스 4개와 고지 문서도 포함했다.
- 앱·설치기는 미서명이며 서명 테이블 크기는 0이다.
- **Windows 실제 설치·업그레이드·제거 및 Windows 125%·150% 화면 배율은 이 Linux 환경에서 검증하지 않았다.**

## 로컬 재현

프로젝트 루트에서 실행한다. Windows x64에서는 `npm ci` 후 `npm run dist:win`을 사용한다. 다음은 Node.js 24 이상과 로컬 Docker를 갖춘 Linux의 빌드 명령이다.

```bash
npm ci
npm run check
npm run build
mkdir -p release
docker run --rm --platform linux/amd64 \
  --mount "type=bind,src=${PWD},dst=/project,readonly" \
  --mount "type=bind,src=${PWD}/release,dst=/project/release" \
  --workdir /project \
  --entrypoint /bin/bash \
  electronuserland/builder@sha256:41ae540902461b6cbc988987db79547fcc10cda04d2a6c6367504f59d4b37c64 \
  -lc 'node node_modules/electron-builder/out/cli/cli.js --win nsis --x64 --publish never'
sha256sum release/wPost-0.1.0-x64-Setup.exe
```

Windows에서 다운로드한 파일은 다음 명령으로 비교한다.

```powershell
Get-FileHash .\wPost-0.1.0-x64-Setup.exe -Algorithm SHA256
```

체크섬은 이번 생성 파일의 식별자이다. 빌드 도구의 타임스탬프 등으로 재빌드 결과는 달라질 수 있다. 설치 확인 항목은 [배포 절차](../releasing.md)를 따른다.
