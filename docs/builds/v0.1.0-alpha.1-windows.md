## 빌드 환경과 검증 범위

Rocky Linux 로컬 환경에서 번들을 생성하고 공식 Docker 이미지로 패키징했다. 컨테이너는 Node.js 24.15.0과 Wine 11.0을 사용했다. Electron 44.7.0, electron-builder 26.15.3, NSIS 3.0.4.1로 빌드했다.

- TypeScript 검사와 프로덕션 번들 생성 성공.
- 7-Zip의 NSIS 아카이브 무결성 검사 성공 (`Everything is Ok`).
- 포함된 `Wook Post.exe`는 x86-64 PE 실행 파일이다. NSIS 부트스트랩 자체는 PE32이며 설치 대상 앱의 아키텍처와 별개다.
- ASAR에 메인·preload·화면·런타임 의존성이 포함되고, 앱 버전과 제작자가 올바른지 확인했다.
- 설치 파일과 앱의 서명 테이블은 비어 있다. 코드 서명은 적용하지 않았다.
- **실제 Windows 설치·업그레이드·실행·삭제는 미검증**이며 사용자가 확인할 예정이다.

이 체크섬은 이번 생성 파일의 식별자이다. 도구의 타임스탬프 등으로 재빌드한 파일의 해시는 달라질 수 있다.

## Linux 로컬 Docker에서 재현

프로젝트 루트에서 실행한다. Node.js 24 이상, npm과 로컬 Docker가 필요하다. Windows 로컬 빌드는 기존 `npm run dist:win`을 사용한다.

```bash
npm ci
npm run build
mkdir -p release
docker run --rm --platform linux/amd64 \
  --mount "type=bind,src=${PWD},dst=/project,readonly" \
  --mount "type=bind,src=${PWD}/release,dst=/project/release" \
  --workdir /project \
  --entrypoint /bin/bash \
  electronuserland/builder@sha256:41ae540902461b6cbc988987db79547fcc10cda04d2a6c6367504f59d4b37c64 \
  -lc 'node node_modules/electron-builder/out/cli/cli.js --win nsis --x64 --publish never'
sha256sum release/WookPost-0.1.0-alpha.1-x64-Setup.exe
```

다운로드한 파일은 Windows PowerShell의 `Get-FileHash .\WookPost-0.1.0-alpha.1-x64-Setup.exe -Algorithm SHA256`으로 비교할 수 있다.

근거: [electron-builder 멀티 플랫폼 빌드 문서](https://www.electron.build/docs/features/multi-platform-build/). 설치기 동작 확인 항목은 [배포 체크리스트](../releasing.md)를 따른다.
