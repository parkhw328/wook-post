# wPost 0.2.0 기능·호환성 점검

## 변경 범위

- wShell의 주황색 w 대신 wPost 전용 파란색 P 아이콘을 적용한다. SVG 원본에서 앱 PNG와 Windows ICO 7개 크기를 생성한다.
- 컬렉션 이름 변경과 삭제를 제공한다. 기본값은 요청 보존이며, 선택하면 포함된 저장 요청도 삭제한다.
- 영문·한글 글꼴 선택과 전체 글자 크기 80–150% 설정을 제공한다. 미리보기·취소·기본값 복원·저장 후 재실행을 지원한다.

## 데이터 보존 기준

컬렉션 이름을 바꿔도 컬렉션 ID와 요청 내용은 바뀌지 않는다. 컬렉션만 삭제하면 요청의 `collectionId`만 `null`로 바꾼다. 열린 탭은 컬렉션 참조만 갱신하고 기존 편집 여부를 유지한다. 요청까지 삭제했을 때 열린 탭은 내용을 남기고 미저장 상태로 전환한다. 다시 저장하면 미분류 요청으로 저장할 수 있다. 모든 삭제 방식에서 과거 요청·응답 히스토리는 유지한다.

글꼴 설정은 기존 SQLite에 `appearance` 테이블을 추가해 보관한다. 이전 DB에 설정이 없으면 JetBrains Mono·Noto Sans KR·100%를 적용한다. 잘못된 크기·글꼴 입력은 메인 프로세스에서 거절하며, 읽을 수 없는 표시 설정은 기본값을 사용해 기존 요청에 계속 접근할 수 있다. 설정을 저장하기 전 미리보기는 DB를 바꾸지 않는다.

설치 식별자 `com.parkhw328.wookpost`, 데이터 경로 `Wook Post/wook-post.sqlite`, SQLite `user_version: 1`, 백업 `schemaVersion: 1`은 유지한다. 백업의 데이터 범위는 기존과 같고 PC별 화면 설정은 포함하지 않는다.

## 자동 검증

- 단위·통합 테스트 35개: 기존 통신·백업·SQLite·JSON 보존과 컬렉션 이름 변경/삭제 범위/입력 검증, 기존 DB 확장, 설정 영속성·오류 복구를 확인했다.
- 실제 Electron 시나리오 8개: 기존 요청→저장→백업→가져오기→재실행, 인증·환경 변수·취소·응답 복사·히스토리 페이지에 더해 아래 흐름을 확인했다.
  - 컬렉션 이름 변경, 삭제 취소, 요청 보존 삭제, 탭 상태·히스토리 유지, 재실행 후 데이터 확인.
  - 요청을 포함한 삭제, 열린 편집 내용과 응답 유지, 미저장 종료 보호, 미분류로 다시 저장.
  - 영문·한글 글꼴과 크기 미리보기·취소·저장·재실행·기본값 복원, Esc 취소, 150%에서 실제 OPTIONS 전송.
- 기본 창 1440×940과 최소 창 1000×700을 확인했다. 최대 크기에서 설정창의 저장·취소 버튼을 고정하고 내용만 스크롤하도록 보완했다.
- 디자인 자산 라이선스 고지를 새 아이콘 출처에 맞게 갱신했다. 기본 글꼴은 번들 파일을 사용하고, PC에 없는 선택 글꼴은 기본 글꼴로 대체한다.

검증은 로컬 HTTP 서버와 임시 SQLite를 사용했다. 실제 사용자 데이터는 변경하지 않았다. 화면은 `docs/screenshots/`에 기록한다.

## 남은 확인 범위

Windows 실제 설치·업그레이드·제거, Windows 배율별 표시, 작업표시줄 고정 아이콘 갱신은 Linux에서 직접 확인하지 않았다. 오래된 고정 아이콘이 남으면 업데이트된 앱을 실행한 뒤 작업표시줄에서 다시 고정해 확인한다. PC별 설치 글꼴의 실제 모양은 해당 Windows 환경에서 확인해야 한다.

설치 파일의 아카이브·버전·새 아이콘 리소스 확인 결과는 [Windows 빌드 기록](../builds/v0.2.0-windows.md)에 정리한다.
