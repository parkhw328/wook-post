### rules
1. 작업한 내용들은 ./rules/rules.md에 정리하면서 진행하자.
2. 버전에 대한 관리가 필수로 중요할 듯해. 커밋 푸시되면서의 내용들을 버전관리하면서 가줘.
3. 사용자 직관적인 UI/UX 인터페이스로 작성해야해.

### requirements
1. postman의 무료버전+ postman과 유사한 기능을 분석하고 조립해서 가장 근사한 ajax 통신용 프로그램을 만들고 싶어.
 - postman을 벤치마킹하면서 유사한 기능이 있는 애플리케이션을 조사하고, 뛰어넘는 성능의 프로그램을 만들고 싶은거야!
2. 사용자 직관적인 UI/UX 인터페이스로 작성해야해.
3. 결과에 대한 import / export가 확실해야 하고.
4. 히스토리를 로컬에 저장해두고선 import / export 할 수도 있어야 할 거 같아.
5. 설치형태로 만들어주고 install shield형태로 만들어줘. 빌드는 로컬에서 해야해.
 - 제작자는 Hyunwook Park(parkhw328@gmail.com)로 해서 넣어주면 좋겠어.
6. 기본 windows 64bit에 설치해서 사용할 거니 맞춰주길 바라고.
